AI 게임 만들기 동아리 · 5주차 2부

🛸 Antigravity로 내 게임 더 만들기

1부에서 Gemini로 멘토 피드백을 반영해 게임을 보완했어요.
이제 내 컴퓨터의 게임 폴더를 AI 에이전트에게 맡겨서, 기획서를 보고 게임을 더 완성해요.

① 오늘의 흐름

사이트 5주차 작성하기 화면의 🚀 상자 7~10단계
🤖1부 Gemini 보완 · 중간 저장
⬇️Antigravity 설치 · 로그인
📁게임 폴더 만들기
💬프롬프트 보내고 제안 고르기
🎮직접 해 보고 고치기
📜패치노트 → 다음 버전 올리기

1부에서 원하는 게임이 나온 다음에 2부를 시작해요. 1부 결과를 먼저 올려 두면(예: ver3), 2부가 잘 안 돼도 제출한 게임이 남아요.

② Antigravity는 뭐가 달라요?

Gemini vs Antigravity
🤖 Gemini (1부)내가 묻고 → Gemini가 코드를 보여 주고 → 내가 복사해서 붙여 넣어요.
대화 한 번에 한 가지씩 고치기 좋아요.
🛸 Antigravity (2부)내 컴퓨터 폴더 안의 파일을 에이전트가 직접 읽고, 고치고, 실행해서 확인해요.
먼저 계획을 보여 주고, 내가 고르면 그대로 일해요.

에이전트(agent)는 "시키면 스스로 여러 단계를 해내는 AI"예요. 그래서 무엇을 맡길지 내가 정하고, 하는 일을 확인하는 것이 중요해요.

③ 준비물

설치 전에 확인
💻내 컴퓨터Windows 10 (64비트) 이상, 또는 macOS 12 이상
인텔(x86) 맥은 안 돼요
🌐Chrome에이전트가 게임을 열어 확인할 때 써요
📧개인 Gmail 계정학교·회사 계정이 아닌 개인 계정으로 로그인해요

⚠️ 학교 컴퓨터는 설치 권한이 없을 수 있어요. 설치가 막히면 억지로 하지 말고 선생님께 알려 주세요.

④ 설치하고 로그인하기

처음 한 번만 · 5~10분
  1. antigravity.google/download ↗에 들어가 내 컴퓨터에 맞는 설치 파일을 받아요. (Windows는 .exe, 맥은 .dmg)
  2. 설치 파일을 실행해요. Windows에서 "PC 보호" 파란 창이 뜨면 추가 정보 → 실행을 눌러요.
  3. 설치가 끝나면 Antigravity를 열고 Google로 계속하기를 눌러 개인 Gmail 계정으로 로그인해요.
  4. 브라우저에서 로그인을 마치면 Antigravity 열기를 눌러 앱으로 돌아와요.
  5. 테마를 고르고 약관을 읽은 뒤 수락 → 완료를 눌러요. 다른 설정은 기본값 그대로 두면 돼요.
  6. Antigravity IDE 설치 버튼이 보여도 오늘은 설치하지 않아도 돼요.

⑤ 내 게임 폴더 만들고 프로젝트로 열기

사이트 8단계
  1. 바탕 화면에 영어 이름 폴더를 만들어요. (예: my-game)
  2. 사이트 5주차 🚀 상자 8단계 💾 game.html · 기획서.md 내려받기를 눌러요.
  3. 다운로드 폴더에 생긴 두 파일을 my-game 폴더로 옮겨요.
  4. Antigravity 왼쪽 프로젝트에서 새 프로젝트를 만들고 my-game 폴더를 골라요.
  5. 첫 번째 대화 시작(또는 새 대화)을 눌러요.
📁 my-game
 ├─ 🎮 game.html ← 1부에서 보완한 내 게임
 └─ 📄 기획서.md ← 3주차 게임 기획서

에이전트가 일하면 이런 파일이 생겨요
 ├─ 🗂 game-backup.html ← 고치기 전 백업
 └─ 📜 patchnote.txt ← 마지막에 받는 패치노트

프로젝트에는 내 게임 폴더만 넣어요. 바탕 화면 전체나 문서 폴더를 통째로 넣지 마세요. 에이전트는 프로젝트에 넣은 폴더 안에서 일해요.

⑥ 에이전트에게 맡기기

사이트 9~10단계
  1. 사이트 9단계 📋 Antigravity 프롬프트 복사를 누르고, 대화 칸에 붙여 넣어 보내요.
  2. 에이전트가 기획서 ↔ 지금 게임 비교표와 이어서 만들 것 3가지를 보여 줘요. 읽어 보고 "1번이랑 3번 좋아"처럼 골라요.
  3. 에이전트가 파일을 고치거나 명령을 실행해도 되는지 물어보면, 무엇을 하려는지 읽어 보고 허락해요.
  4. 다 되면 폴더의 game.html을 더블클릭해 Chrome에서 직접 해 봐요. 이상한 곳은 하나씩 말해서 고쳐요.
  5. 사이트 10단계 📋 패치노트 요청 프롬프트를 보내면 patchnote.txt가 생겨요.
  6. 사이트 5단계에 patchnote.txt를 올려 개발일지에 반영하고, 6단계에서 폴더의 game.html을 골라 다음 버전(예: ver4)으로 올려요.
💡 요청 잘하는 법 · 한 번에 한 가지씩: "손님 대기 시간을 5~12초 사이에서 랜덤으로 바꿔 줘" · 숫자로 말하기: "느려" 대신 "속도를 3에서 2로" · 결과 알려 주기: "됐어 ✅" / "점프는 되는데 착지할 때 벽에 끼어 🔺" · 망가졌으면: "game-backup.html 상태로 되돌려 줘"

⑦ 안전하게 쓰는 약속

꼭 지켜요
📁 프로젝트에는 내 게임 폴더만 넣어요.
👀 허락을 물어보면 읽고 나서 눌러요. 파일·폴더를 지우는 명령이나 무슨 뜻인지 모르는 명령이면 허락하지 말고 선생님께 물어봐요.
🔒 비밀번호, 열쇠(토큰), 개인 정보는 대화에 절대 넣지 않아요.
🎯 기획서에 없는 큰 기능을 에이전트가 마음대로 넣으면 "기획서에 있는 것만 해 줘"라고 말해요.

⑧ 잘 안 될 때

자주 묻는 질문
로그인이 안 돼요

학교·회사 계정이 아니라 개인 Gmail 계정으로 로그인했는지 확인해요. 그래도 안 되면 선생님께 알려 주세요.

"사용량을 다 썼다"는 메시지가 나와요

무료로 쓸 수 있는 양에는 한도가 있어요. 잠시 기다렸다가 다시 하거나, 남은 수정은 1부처럼 Gemini에서 이어서 해요.

에이전트가 게임을 처음부터 새로 만들어 버렸어요

"game-backup.html로 되돌리고, 지금 게임에서 이어서 고쳐 줘. 새로 만들지 마"라고 말해요.

폴더에 game.html이 없어요

사이트 6단계에서 1부 게임을 아직 안 올렸다면 8단계 버튼으로 받은 게임이 4주차 ver2일 수 있어요. 6단계 💾 html 내려받기로 받은 파일 이름을 game.html로 바꿔서 폴더에 넣어요.

설치 파일이 실행되지 않아요

학교 컴퓨터는 설치가 막혀 있을 수 있어요. 억지로 하지 말고 선생님께 알려 주세요. 오늘은 1부(Gemini) 결과로 제출해도 돼요.
