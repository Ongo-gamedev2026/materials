# 📚 온고 게임제작반 수업 자료실

👉 https://ongo-gamedev2026.github.io/materials/

선생님이 주차별 학습지와 수업 자료를 올리는 공간이에요. 학생은 읽기만 할 수 있어요.

## 자료 올리는 방법
1. 해당 주차 폴더(`week1` ~ `week6`)에 들어가서 **Add file → Upload files**로 자료를 올려요.
   - 파일 이름은 **영어, 숫자, `-`, `_`** 만 쓰세요. (한글 이름은 업로드가 잘 안 될 수 있어요)
2. `materials.json`을 열고 연필 아이콘으로 해당 주차 `files`에 한 줄을 추가해요.

```json
{ "name": "화면에 보일 자료 이름", "file": "올린-파일-이름.html" }
```

3. 1~2분 뒤 자료실 주소에서 확인해요.

## 바로 가는 주소 형식
`https://ongo-gamedev2026.github.io/materials/week1/파일이름`
